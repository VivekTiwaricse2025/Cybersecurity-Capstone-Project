# Cybersecurity-Capstone-Project
Python-based Security Log Analyzer and Threat Monitoring Dashboard.
SecureLog Analyzer is a small defensive cybersecurity dashboard. It reads authentication log records, counts failed logins by IP address, flags repeated failures, highlights successful logins from an IP that also had repeated failures, and lets the analyst download parsed records as CSV. Why this project: it demonstrates practical blue-team monitoring and basic security analytics without scanning, attacking, or changing any external system. Project objectives • Build a working cybersecurity solution (log analyzer dashboard). • Demonstrate defensive security skills through parsing, detection rules, review findings and reporting. • Document the architecture, test cases, limitations and safe-use boundaries. • Publish the source code to GitHub and deploy a live demo if desired. Tools required • Laptop/PC with internet access. • Python 3.10 or newer. • A code editor such as VS Code (optional). • A web browser. • Git and a GitHub account for repository submission. • Streamlit Community Cloud account for optional live deployment. Important: use only logs from a computer or environment you own or have explicit permission to monitor. The included sample data is fictional documentation data. 2. Project architecture Data flow: Text log file → input validation and parsing → event table → detection rules → dashboard findings → CSV export.
